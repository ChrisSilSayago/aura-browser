# Aura (Clon de Safari)

Un navegador web minimalista inspirado en el diseño de Safari, desarrollado con Python, PySide6 y QtWebEngine. 

Hecho con la intención de aprender, experimentar y ofrecer una interfaz limpia en escritorios Linux.

## Características
* Interfaz minimalista y fluida.
* Navegación web integrada gracias a QtWebEngine.
* Diseñado pensando en la estética de escritorios modernos (como KDE).

## Requisitos
* Python 3.x
* PySide6
